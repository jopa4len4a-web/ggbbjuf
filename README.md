# TwaragaSwap

Бот обменника с мини-приложением: клиент пополняет баланс чеком CryptoBot / xRocket,
создаёт заявку, менеджер выплачивает по номеру телефона.

## Запуск на BotHost

1. Создайте бота в @BotFather, скопируйте токен.
2. В BotHost создайте бота (Python), загрузите этот архив, включите использование своего `Dockerfile`.
3. Подключите домен **gxbtbzht.bothost.tech**, порт веб-приложения — **3000**.
4. Переменные окружения:

| Переменная | Нужна? | Значение |
|---|---|---|
| `BOT_TOKEN` | да | токен бота (BotHost обычно передаёт сам) |
| `DOMAIN` | желательно | `gxbtbzht.bothost.tech` (это же значение по умолчанию) |
| `PORT` | желательно | `3000`, как в настройках бота |
| `OWNER_ID` | рекомендуется | ваш числовой Telegram ID |
| `OWNER_USERNAME` | нет | по умолчанию `ownerparadoxy` |
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` | нет | можно ввести в админ-панели |

5. Деплой. После изменения порта или домена нужен повторный деплой.
6. Проверка: `https://gxbtbzht.bothost.tech/health` отвечает `ok`.

Запускайте только **одну** копию бота. База и сессия лежат в `/app/data` — делайте её копии.

## Первая настройка

1. С аккаунта @ownerparadoxy нажмите `/start` и откройте приложение. Роль владельца закрепится за вашим ID.
2. **Админ → Курс и часы**: задайте курс (пока он 0, заявки не принимаются), лимиты, часы, часовой пояс.
3. **Админ → Аккаунт**: подключите отдельный Telegram-аккаунт для чеков (api_id и api_hash с my.telegram.org,
   номер, код, пароль 2FA). С этого аккаунта заранее нажмите Start в @send и @xrocket, язык — русский или английский.
4. **Админ → Админы**: добавьте менеджеров по юзернейму. Каждый должен нажать `/start`.
5. Проверьте на маленьких суммах (см. ниже).

## Проверка перед открытием

- [ ] Чек CryptoBot на 0,5–1 USDT зачислился на ту же сумму.
- [ ] Чек xRocket на 0,5–1 USDT зачислился на ту же сумму.
- [ ] Повторная отправка того же чека отклоняется.
- [ ] Заявка пришла менеджеру, кнопки работают, «Пришло / Не пришло» зелёная и красная.
- [ ] Видео после «Не пришло» дошло менеджеру.

Если чек ушёл «на ручную проверку», владельцу придёт точный ответ бота. Зачислите вручную в
**Админ → Чеки**. Шаблон распознавания — `SUCCESS_RE` в `app/cheques.py`.

## Как идёт заявка

новая → менеджер «Принять» → «Дать сумму» (не больше остатка, с подтверждением) → таймер 15 мин →
клиент «Пришло» / «Не пришло» → «Завершить» (можно и без единой выплаты).

- Доллары списываются с баланса при создании заявки.
- Выплачивать можно частями; пока по одной части нет ответа, следующую создать нельзя.
- «Завершить» возвращает клиенту на баланс всё, что не выплачено; перед этим показывает суммы.
- Выплаченным считается подтверждённое клиентом и то, по чему он промолчал до конца таймера.
- Пока идёт таймер, завершить нельзя: дождитесь ответа или отмените выплату.
- При споре «Не пришло» решает клиент («Пришло») или владелец («Деньги дошли» / «Не дошли»).

## Роли

| Действие | Админ | Владелец |
|---|---|---|
| Заявки, переписка | свои и новые | все |
| Курс, часы, лимиты ордера, таймер | да | да |
| Админы, аккаунт, чеки на проверке, балансы, принудительное закрытие | нет | да |

## Чеки

Автоматически зачисляются только USDT и USDC (1:1) до лимита (по умолчанию 1000 $).
Другие монеты, крупные суммы и непонятные ответы бота — на ручную проверку.
