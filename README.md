# TwaragaSwap — Telegram Exchange Bot for BotHost

Демонстрационный проект для BotHost (Python 3.11+, порт 3000).

## Что есть
- Telegram-бот и Mini App без отдельной регистрации: профиль создаётся по Telegram ID.
- SQLite: пользователи, курс, заявки, история действий.
- Mini App: расчёт по курсу и создание заявки.
- Админ-панель в Mini App: изменение курса, просмотр заявок, управление статусом.
- Рассылка всем пользователям: текст, фото с подписью, HTML и URL-кнопка.
- Проверка Telegram WebApp initData на сервере.
- Роли: главный администратор и дополнительные администраторы/менеджеры.
- Ограничение суммы и подтверждение создания заявки.

## Ограничения этой версии
Это безопасный демонстрационный каркас. В нём НЕТ реального приёма криптовалюты,
проверки CryptoBot/XRocket-чеков, банковских выплат или реального зачисления средств.
Баланс и платежные события не имитируются как настоящие. Не подключайте реальные деньги
до юридической проверки, проверки провайдера и независимого аудита безопасности.

Вместо сбора банковских логинов, полных выписок или видео банковской истории
используйте номер заявки и безопасный идентификатор транзакции. Не просите пользователей
передавать пароли, коды подтверждения, данные карты или полную историю операций.

## Установка на BotHost
1. Загрузите содержимое архива в корень проекта.
2. Установите зависимости из `requirements.txt`.
3. Укажите переменные окружения:
   - `BOT_TOKEN` — токен Telegram-бота
   - `WEBAPP_URL` — публичный HTTPS URL приложения
   - `OWNER_USERNAME=ownerparadoxy` — username главного администратора без `@` (по умолчанию уже задан)
   - `ADMIN_IDS` — рекомендуемый дополнительный способ закрепить главного администратора по числовому Telegram ID
   - `PORT=3000`
4. Запустите: `python main.py`
5. В BotFather настройте Menu Button на `WEBAPP_URL`.

Главный администратор `@ownerparadoxy` получает роль owner после первого `/start`, если username совпадает с `OWNER_USERNAME`. Для надёжности дополнительно укажите его числовой Telegram ID в `ADMIN_IDS`, поскольку Telegram username может измениться.
Главный администратор может добавить менеджера командой `/addadmin @username` (пользователь должен предварительно запустить бота) или `/addadmin <telegram_id>`. Удаление: `/deladmin <telegram_id>`.

## Рассылка
Главный администратор или менеджер отправляет `/broadcast`.
Затем отправляет текст или фотографию с подписью. Бот показывает подтверждение.
`/cancel` отменяет создание рассылки. Отправка идёт всем пользователям, которые
когда-либо запускали бота и не заблокировали его.

## Настройка
- Название: TwaragaSwap. Начальный курс: 97.0 (условные единицы на 1 USD). По умолчанию обменник открыт, график: ежедневно 10:00–22:00 (локальное время)
- Лимит заявки: 1–5000 USD, настраивается через переменные `MIN_ORDER_USD`, `MAX_ORDER_USD`.
- Курс меняется в админ-панели Mini App.

## Тестовый сценарий передачи чека менеджеру

Команда пользователя: `/demo_check описание_тестового_чека`. Бот передаст текст всем добавленным администраторам/менеджерам. Менеджер отвечает на сообщение бота одним числом (например, `12.50`), после чего тестовая сумма сохраняется и отправляется пользователю. Если ни одному менеджеру не удалось доставить сообщение, заявка помечается `manual_review`.

Это только демонстрация ручного ввода суммы: бот не проверяет подлинность реальных CryptoBot/XRocket-чеков и не выполняет выплаты. Не отправляйте реальные чеки, банковские данные, пароли или коды.
